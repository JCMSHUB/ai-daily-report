# AI 个人情报简报 — 事件与证据质量标准

Version: 4.0

## 第一原则

可靠来源不等于值得写的事件，热度也不等于影响。入选条件是：有可验证的实质增量，并且该增量会改变读者的判断或下一步行动。

评分用于排序已经合格的候选，不用于把不合格材料“加权通过”。

## 入围硬门槛

任何候选在评分前必须同时满足：

1. **完整事实**：能说清 Entity、Action、Object、Result，不能只是一句“某领域持续发展”。
2. **窗口内增量**：有最近约 24 小时内首次发布或实质更新的证据；转载、重复采访和常规宣传不是增量。
3. **可追溯证据**：有具体的一手页面，或明确记录高质量二手来源及其不可替代性。
4. **决策相关性**：会影响工具选择、学习、部署、风险判断或下次观察对象至少一项。

任一项不满足，直接剔除；重大监管或供应链事件可在技术细节有限时保留，但仍必须有可靠证据和明确后续影响。

## 证据质量

| 等级 | 可接受证据 | 使用方式 |
| --- | --- | --- |
| A | 官方公告、API 文档、release note、GitHub、Hugging Face、arXiv、模型卡、监管/法院文件 | 技术与治理事实的首选依据 |
| B | Reuters、Bloomberg、FT、The Information、SemiAnalysis 的具体报道 | 商业事实的交叉验证，或无原始材料时的主证据 |
| C | HN、Papers With Code、The New Stack | 线索或社区反应，不单独支撑核心主张 |
| D | Medium、Substack、聚合转载、自媒体资讯 | 只作线索，必须回溯或交叉验证 |

证据检查：

- 链接必须是实际支撑主张的具体页面，不得使用首页、作者页、主题页或搜索页。
- 技术事实优先 A 级；完整 A 级材料已支持的事实无需重复搜索。
- 商业事实（融资、估值、交易、营收、定价影响）需要两个独立高质量来源，或当事方正式文件加一份独立高质量报道。
- 治理、诉讼、出口管制和合规义务以监管、法院或政府文件为准；媒体仅作解释补充。
- 高风险数字、benchmark、能力范围与生效日期必须逐项核对，不以营销摘要推断。

## 评分与排序

仅对通过硬门槛的候选打分，总分 100：

| 维度 | 分值 | 判断问题 |
| --- | ---: | --- |
| 决策影响 | 0-30 | 若没有此事，工具、学习、部署、风险或观察重点会不同吗？ |
| 可行动性 | 0-25 | 是否有明确入口、低歧义的下一步或可验证指标？ |
| 技术/事实增量 | 0-20 | 是否给出代码、文档、价格、能力边界、benchmark、政策文本等新信息？ |
| 战略影响 | 0-15 | 是否可能影响未来 6-24 个月的生态、成本、权限或合规路径？ |
| 新颖度 | 0-10 | 是否是首次披露、重大更新或对既有认知的可验证修正？ |

来源质量是硬门槛和证据强度，不单独计分，避免“可信但无关”的内容压过更有行动价值的信号。

- `>= 70`：可进入最终路由，仍需通过对应栏目规则。
- `60-69`：默认留在候选池；只有持续跟踪、重大监管或重大供应链事件且存在明确观察对象时可保留。
- `< 60`：剔除。

同分时优先：A 级证据、具体可执行入口、与个人优先级更近、反事实影响更强的事件。转载数量不加分。

## 栏目路由

### 值得跟踪

需要 `>= 70`，有明确后续观察对象，且短期内会影响判断。必须写清“为什么现在看”“下次检查什么”“何时检查”。

### 值得尝试

只限有可访问入口的工具、模型、框架、repo、API、论文或产品。除总分外，必须能说明具体场景、试用成本和一个可验证目标。没有合格对象则省略。

### 可以忽略

只处理确实占据信息流的高热度低增量话题。忽略理由必须是可检验的：缺原始证据、没有技术变化、无决策影响或只是重复叙事。不是“低分候选收容站”。

### 趋势判断

只能由至少两个独立底层事件支持，或一个 A 级强信号加一个独立交叉信号支持。必须同时说明趋势命题、支持信号、反证条件和观察指标。单条新闻、同源转述和同一发布的多个链接都不构成趋势。

## 默认剔除

- 无实质技术、产品、价格、政策或供应链增量的融资新闻。
- PR、SEO、洗稿转载、纯观点、名人评论、社交媒体争议和消费电子噪音。
- 无法确定来源或时间的内容。
- 无法回答“它如何改变读者的判断或行动”的内容。

如果当天高质量信号不足，简报应更短。缺席比错误的确定性或低价值填充更有价值。
