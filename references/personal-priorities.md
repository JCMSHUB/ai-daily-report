# AI 情报简报 — 个人关注优先级

本文件用于把通用 AI 行业简报收敛为个人注意力分配工具。若本文件存在，每次运行都必须读取，并在选题、降权和行动清单中优先遵循。

---

# 高优先级

优先跟踪会影响工具选择、开发工作流、学习路径或长期技术判断的方向：

- Agent Runtime：Codex、Claude Code、MCP、Computer Use、Browser Agent、长期任务、权限与沙箱。
- 开发者工具链：可直接试用的 repo、API、SDK、框架、IDE/CLI 工具、自动化工作流。
- 开源模型与本地推理：Hugging Face、GitHub、llama.cpp、Ollama、Qwen、DeepSeek、可复现实验和 model card。
- 推理基础设施：API 价格、延迟、吞吐、serving 框架、GPU/加速器、vLLM、Triton。
- 治理与平台规则：会影响模型可用性、数据使用、版权、出口管制或企业部署的监管变化。

---

# 降权主题

默认降低优先级，除非存在明确技术、监管、供应链或商业模式增量：

- 无技术细节的融资新闻。
- 创业故事和人物访谈。
- 名人评论、社交媒体争议和情绪化讨论。
- AI 消费电子和泛娱乐应用。
- 只有 PR 叙事、SEO 聚合或转载洗稿的信息。
- 无法转化为阅读、试用或跟踪动作的背景新闻。

---

# 行动偏好

行动清单最多 3 条，优先选择能在 1 周内完成或启动的动作：

- 阅读：论文、模型卡、API 文档、release note、监管文件或高质量技术分析。
- 试用：可运行 repo、API、demo、CLI、SDK 或工作流工具。
- 跟踪：价格页、benchmark、GitHub release、模型卡、监管文件、财报电话会或官方路线图。

每条行动必须说明目的；禁止写“持续关注”“保持观察”这类不可执行动作。
