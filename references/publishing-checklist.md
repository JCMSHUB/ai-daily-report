# AI 情报简报发布前最终自检清单

Version: 4.3

目标是防止未经验证、无决策价值或为填充而写的内容进入 Get笔记。

## 1. 候选与证据

- [ ] 写作前已形成候选事件筛选表：事件键、事件与时间、前一/当前状态、相对本地近期简报或来源时间线的实质增量、主要来源与等级、决策影响、评分、Verification 状态、唯一主栏目或剔除原因。
- [ ] 日报已检查本地最新最多 3 期，周报已检查本周最新最多 7 期；只读取候选关键词命中段落。目录为空或不存在时已明确记录，并用一手来源时间线建立前一状态。
- [ ] 每个正文事件都通过完整事实、窗口内增量、可追溯证据、决策相关性四个硬门槛。
- [ ] 已按底层事件去重；同源转载和多个链接未被当成多个信号。
- [ ] 只对入围候选执行 Verification；每次 extract 仅处理 1 个原始 URL 并使用聚焦 query，同一 URL 失败后没有重试。
- [ ] 疑似旧闻最多进行 1 次定向日期核查；snippet 只用于剔除或定位来源，没有用于验证入选主张。
- [ ] 技术与治理事件引用了可获得的一手材料；预期存在但无法定位一手材料的候选已剔除；商业主张有两个独立 B 级来源或当事方文件加独立 B 级报道。
- [ ] 每项核心主张都有原子事实、发布状态、事件时间、证据 URL、证据原文或准确释义、来源等级和验证结果。
- [ ] 数字、benchmark、能力边界、价格、生效日期与监管要求逐项有证据；预告、预览、可用、权重发布和 GA 没有混用。
- [ ] 每个链接是具体证据页，不是首页、作者页、主题页或搜索页。

## 2. 判断与路由

- [ ] 每个常规“今日结论”能指向正文证据；低信号结论明确写出扫描窗口、覆盖范围和无候选通过硬门槛，不伪装成事件事实。
- [ ] 每项正文清楚区分事实、判断与行动/观察；推断没有伪装成确定事实。
- [ ] 每项都能回答：如果此事没有发生，读者的判断或下一步是否会不同？若不会，已剔除。
- [ ] 每个底层事件只进入一个正文主栏目；结论、趋势和行动没有把同一事实重新包装成新项目。
- [ ] `值得跟踪` 有具体下次检查对象和时间。
- [ ] `值得尝试` 有场景、最小验证、成本和入口；没有合格对象时已省略。
- [ ] `可以忽略` 只解释真实高热度噪音，理由具体；没有此类话题时已省略。
- [ ] 趋势判断由至少两个不同、已通过 Verification 且已进入正文的底层事件支持；第二来源未被误算为第二事件，趋势段落没有引入新事实；不满足则已省略。
- [ ] 行动清单不超过 3 条，且每条有对象、目的、完成条件和时间。
- [ ] 低信号期没有泛化追查，只保留低信号结论、扫描依据和时间底注，其余栏目全部省略。

## 3. 表达与格式

- [ ] 没有为主题覆盖、栏目完整性、调用预算或篇幅填充内容。
- [ ] 标题层级连续，使用标准 Markdown；没有 HTML、style、iframe、富文本或引用块。
- [ ] 单条 bullet 不超过 180 个中文字符，信源使用普通列表或同级链接。
- [ ] 仅保留已验证的中文表述；没有空泛分析、重复结论或无来源的因果断言。
- [ ] 正文不超过 8000 个中文字符，且不以最低长度为目标。
- [ ] 底部含真实数据截至时间（CST）。

## 4. 发布

- [ ] Markdown 文件生成成功。
- [ ] 已成功执行 `python3 scripts/save-to-getnote.py <markdown_file>`。
- [ ] 返回有效访问链接。
- [ ] 笔记已归档到指定知识库。
- [ ] Markdown 已写入本地近期简报目录，过期文件清理没有报错。

任一证据、判断或发布项不通过时，必须删除、降级、补证或重试；本地 Markdown 仅是故障产物，不等同于发布成功。

最终读者测试：只读“今日结论”和“我的行动清单”，是否能知道今天应读、试、跟踪什么，以及为什么？若不能，重新组织简报。
